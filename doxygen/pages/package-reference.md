# Package Reference {#package-reference}

The generated API reference uses the Java packages below. Each package now has a
`package-info.java` source file so Doxygen can build package-level reference
pages in addition to this maintainer-oriented overview.

| Package | Description |
|---------|-------------|
| `com.tlcsdm.jvmexplorer` | Desktop application entry points and top-level controllers. |
| `com.tlcsdm.jvmexplorer.agent` | Runtime agent code injected into target JVM processes. |
| `com.tlcsdm.jvmexplorer.agent.launch` | Launch-time agent helpers. |
| `com.tlcsdm.jvmexplorer.bytecode` | Bytecode decompilation, disassembly and assembly helpers. |
| `com.tlcsdm.jvmexplorer.bytecode.compile` | In-memory Java compilation support. |
| `com.tlcsdm.jvmexplorer.fx` | Shared JavaFX UI utilities and controls. |
| `com.tlcsdm.jvmexplorer.fx.classes` | Class browser views and class-tree UI logic. |
| `com.tlcsdm.jvmexplorer.fx.compile` | UI for compiling and applying Java source changes. |
| `com.tlcsdm.jvmexplorer.fx.jvms` | JVM discovery and selection UI. |
| `com.tlcsdm.jvmexplorer.fx.method` | Method modification UI. |
| `com.tlcsdm.jvmexplorer.fx.openclass` | Open-class dialogs and related UI. |
| `com.tlcsdm.jvmexplorer.helper` | Application helper utilities. |
| `com.tlcsdm.jvmexplorer.net` | Client-side connection and packet response handling. |
| `com.tlcsdm.jvmexplorer.preferences` | Persistent application preference handling. |
| `com.tlcsdm.jvmexplorer.protocol` | Shared protocol messages, descriptors and configuration models. |
| `com.tlcsdm.jvmexplorer.protocol.helper` | Shared protocol helper utilities. |
| `com.tlcsdm.jvmexplorer.settings` | Application settings and configuration UI support. |
